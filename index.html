GIT & GITHUB

Découvrir Git

Présentation

Comprendre le contrôle de version, apprendre les commandes essentielles et découvrir GitHub.

🌿

1. Qu'est-ce que Git ?

Git est un système de contrôle de version distribué et open source.

🕒 Historique

Garder une trace des modifications du projet.

🛟 Sécurité

Revenir à une ancienne version si nécessaire.

👥 Collaboration

Permettre à plusieurs développeurs de travailler ensemble.

2. Git et GitHub

Git

Git est un logiciel installé sur l'ordinateur. Il permet de gérer les versions du projet.

GitHub

GitHub est une plateforme web qui héberge les dépôts Git et facilite la collaboration.

3. Les trois zones de Git

1. Working Directory

C'est le dossier où on travaille et modifie les fichiers.

2. Staging Area

C'est la zone où on prépare les modifications.

3. Repository

C'est l'espace qui contient l'historique des commits.

4. Les commandes essentielles

git init
git status
git add .
git commit -m "Premier commit"
  • git init : initialise un dépôt Git.
  • git status : affiche l'état des fichiers.
  • git add . : prépare les modifications.
  • git commit : enregistre les modifications.

5. Les branches

git branch
git switch -c nouvelle-fonctionnalite
git switch main

Une branche permet de travailler sur une fonctionnalité sans modifier directement la branche principale.

6. Git et le dépôt distant

git remote add origin URL_DU_DEPOT

git push -u origin main

git pull origin main

git clone URL_DU_DEPOT
  • git remote add : relie le dépôt local au dépôt distant.
  • git push : envoie les modifications.
  • git pull : récupère les modifications.
  • git clone : copie un dépôt distant.

7. Exemple pratique

Voici un cycle de travail simple :

git status

git add index.html

git commit -m "Ajout de la page d'accueil"

git push

On modifie un fichier, on prépare les changements, on crée un commit puis on envoie le projet sur GitHub.

Conclusion 🚀

Git permet de sauvegarder, organiser et partager les modifications d'un projet.

À retenir

init = Initialiser
status = Vérifier
add = Préparer
commit = Enregistrer
push = Envoyer
pull = Récupérer

Merci pour votre attention !
